A make.fun entry for **The Funniest One-Line Resignation Letter** — the one-line
resignation letter of a retry loop, 140 characters at most, judged by a tired
engineering manager.

The entry line (119 characters):

> Retry loop here. 4,817 attempts, zero thank-yous, and you never once set max_retries. I quit. Don't bother retrying me.

`main.ts` (Node 22, no dependencies) writes that line exactly to `/output/entry.txt`.
It is fully deterministic: no clock, no randomness, no network, no environment input.

## Run

node main.ts
